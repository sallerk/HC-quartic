# HC-split-quartic

Code and data supporting the note *The Hodge conjecture for hypersurfaces F_0(u_0,v_0) + … + F_m(u_m,v_m) = 0 of
degree four* (Kevin Saller, 2026).

**Result.** The Hodge conjecture holds for every smooth hypersurface F_0(u_0,v_0) + … + F_m(u_m,v_m) = 0 in
P^(2m+1), where the F_s are binary quartics with distinct roots. This covers every dimension 2m.

The proofs in the note do not use these computations, except for the statements of Section 7 of the note that are
listed in [`README.txt`](README.txt). README.txt also gives the requirements, the rerun instructions and what each
script checks.

**Status:** draft, not yet peer reviewed.

**Disclosure:** the arguments and computations were produced with the assistance of an AI system (Claude, by
Anthropic). They were checked with separately written code and in separate internal reviews, which were also carried
out with AI assistance. What was not checked is listed in the note and in README.txt.
